# v0.5 Mac demo

[Issue #75](https://github.com/AlesSystems/esmer-market-analytics/issues/75). User scope confirmed on 2026-10-09: use already imported Esmer records, remove the financial/source view choice, and present on the current Mac.

## Selected behavior

The application already has one SQLite database. Imported source records become the automatic workspace whenever present, including an empty imported package. Source loading and failure cannot reveal an unrelated financial dataset. Existing source-free financial installations continue to work. No database migration or reimport is required.

| Destination | Primary job |
| --- | --- |
| Özet | Concise qualified monthly contribution estimate when prepared cost candidates exist; otherwise existing recorded counts lead. |
| Satışlar | Product estimate lookup and paging when supported; otherwise recorded product/document lookup leads. |
| Alışlar ve maliyet | Recorded purchasing invoices and lines, with unavailable financial meanings explicit. |
| Giderler | Existing local expense entry, history, draft protection and completeness. |
| Raporlar | Current source/month estimate, daily and product details, and Excel export when supported. Recorded-only packages show the missing-cost-candidate explanation and preparation/import route. Saved financial reports have an explicit historical archive destination. |
| Ayarlar | One active-data description, import, recovery, text size and existing isolated-test connection controls. |

The existing source hash and shared remembered month govern current analytical pages. Archived reports show their saved month and source. Returning restores the appropriate context and focus. Raw product records may include rows excluded from estimates; the drilldown says so.

Local demo verification found that the existing Mac profile contains a recorded-only package. A validated source-format field in the workspace response selects the appropriate existing presentation automatically. It is capability metadata, adds no source columns, and introduces no user mode selector. The demo never fabricates missing cost candidates. Existing SQL configuration is retained encrypted and disabled for this offline presentation.

## Boundaries

Two independent designs were compared before implementation. The same-family design judge selected A (23/25 versus B's 22/25) and carried forward B's explicit loading/error and archive safeguards.

| Alternative | Decision |
| --- | --- |
| A: Direct imported-source priority, shared summary/products/report presentation | Selected. Reuses existing page and estimate modules with the smallest change in ownership. |
| B: New tagged workspace resolver and separate archive destination | Resolver deferred because it adds a layer without changing the chosen behavior. Its source-error precedence tests and archive separation were adopted. |

[Recorded estimates](../../contracts/recorded-estimates.md) retain their formula, unverified status, return exclusion, unknown amounts, coverage and transient nature. [Monthly product profit](../../contracts/monthly-product-profit.md) retains its separately validated population and immutable history. No renderer financial calculations, source permissions, fields, names, unit mappings or schema changes are added.

The release is an unsigned Apple Silicon Mac demo preview. It preserves application identity and the existing local data path. Private databases and packages remain outside its artifacts. Current-build Windows, independent machine-loss recovery, verified real-source financial semantics and production rollout remain open under the foundation acceptance checklist. Demo delivery does not pass those gates.

## Verification

Synthetic packaged checks exercise source/financial coexistence, empty source, source failure, financial-only compatibility, all five destinations, shared month/restart, record return/focus, expense drafts, archive history, preview-only recovery and matching export. Existing formula, import, recovery and privacy tests remain applicable. Visual inspection uses synthetic data and two bounded rounds at normal and compact zoomed Mac window sizes.

Run `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`, and `npm run package:mac`. Inspect ZIP extraction and launch the extracted app. Windows packaging uses `npm run package:win`; execution and Windows acceptance require their own documented environment. A Mac build cannot pass A07's Windows gates.
