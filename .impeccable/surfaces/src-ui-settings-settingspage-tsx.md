# Ayarlar

Mode: Operate. Eralp opens Ayarlar from the sidebar about once a week. He checks which data is active and how old it is, sees whether the isolated live connection is off, healthy or stale, imports a package or SQL backup, manages backups and sets the text size. Source access stays read-only; nothing here may imply verified financial meaning for source rows.

## Direction contract

THESIS: Ayarlar is a grouted panel of glazed çini tiles. Each tile is one job with its own glaze, its condition and only its next action. It refuses the grey list-of-toggles settings page and the dark console.

OWN-WORLD: Glaze-white tiles set in warm grout. Each tile opens with a saturated glaze band: cobalt for import, turquoise for live connection, coral for backup, saffron for display, ink for about. A round glaze seal in each band carries state. Deep ink is the only colour on pressable controls; glaze colours never sit on buttons. Segoe UI, tabular figures.

STORY: He reads the active-data strip, sees the gap between his data and today, imports or checks the source, adjusts text size, and returns to his reports.

FIRST VIEWPORT: Header with "Ayarlar" and one sentence. A full-width ink tile holds the active data, a coverage strip drawn to exact date proportion up to today, and the view switch. Below, cobalt import and turquoise live tiles sit side by side; coral, saffron and ink tiles follow. Primary actions sit at the foot of each tile.

FORM: Glazed Tile Panel, seventh of my seven grounded candidates, seed key b32790ea. Raises: one action colour; next decision only; name plate and one plain line per tile; proportional coverage strip; file import and live connection never share a tile.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
