The attestation correctly failed rather than treating every negative ID as trusted. This is an inspection setup problem, not financial evidence.

The exact remaining nine tuples subsequently matched public SELECT grants in both master and tempdb on the pinned engine, with the same catalog absence. The repaired audit can bind those observed baseline tuples without claiming their native identity or treating arbitrary negative IDs as safe.
